# 合成大狗叫

支持电脑和手机的十级合成小游戏。相同等级相碰升级，两只 10 级合成可触发“大狗叫”录音。

## 在线游玩

[开始游戏](https://woshimaxfive.github.io/daGouJiao/)

## 项目结构

```text
src/
  js/        游戏逻辑
  css/       页面样式
assets/      图片与音频
vendor/      第三方库及许可证
index.html   网页入口
```

## 本地运行

在项目目录执行：

```powershell
python -m http.server 8080
```

打开 <http://localhost:8080/>。纯静态网页，无需安装 npm 依赖。

## 操作与规则

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 瞄准、投放 | 鼠标移动、点击；方向键移动，空格或回车投放 | 按住拖动，松手投放 |
| 重力模式 | 开启后按住 A/D 倾斜，松开恢复；W 晃动 | 支持运动感应时，开启后倾斜或摇动手机，按提示授权 |
| 重开、音效 | 页面按钮，或 R / M | 页面按钮 |

- 晃动仅作用于已落地的狗，冷却 3 秒；电脑切出窗口会清除倾斜按键。
- 落地或碰撞时沿受力方向挤压、回弹，约半秒回稳；系统开启“减少动态效果”时关闭形变动画。
- 同级相碰升级；两只 10 级合成后清除，获得 200 分，并播放录音、显示文字和光圈，伴随短暂停顿。
- 已落地的狗在警戒线以上停住约 1.5 秒，本局结束。
- 切到后台自动暂停并保存，物理、警戒倒计时和时长停止。用同一浏览器返回可继续；结束或重开会清除续局存档。
- 结算显示分数、时长、投放次数和最高等级。时长从首次投放开始计算，不含后台暂停时间。
- 最高分和音效设置保存在当前浏览器。
- 结算后可保存含成绩与游戏二维码的图片：手机长按保存，电脑点击下载。

## 图片加载

使用 WebP，保留 PNG 原图。优先加载 1～4 级，其余后台加载；慢网时先显示内联缩略图，清晰图就绪后自动替换。加载失败可重试，不中断当前局。

## 音频

录音文件：`assets/dagou-bark.mp3`。静音或重开会停止播放；连续触发时从头播放。
