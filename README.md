# 合成大狗叫

一款支持电脑和手机的合成小游戏。相同等级的大狗碰到一起会升级，共有 10 个等级。

## 在线游玩

[开始游戏](https://woshimaxfive.github.io/daGouJiao/)

## 项目结构

```text
src/
  js/        游戏脚本（规则、物理、存档、音效、分享等）
  css/       页面样式
assets/      狗图与音频
vendor/      第三方物理库及许可证
index.html   网页入口
```

## 本地运行

在项目目录执行：

```powershell
python -m http.server 8080
```

打开 <http://localhost:8080/> 即可游玩。游戏为静态网页，无需安装 npm 依赖。

## 操作与规则

- 电脑：移动鼠标瞄准，点击投放；方向键调整位置，空格或回车投放。
- 手机：按住棋盘拖动瞄准，松手投放。
- 电脑可在棋盘下方开启“重力”：按住 A/D 左右倾斜，松开恢复；W 晃动一次，冷却 3 秒。切出窗口会清除倾斜按键。
- 支持运动感应的手机可在棋盘下方开启“重力”：左右倾斜会持续移动狗堆，摇一摇会让已落地的狗弹起挪动，摇动冷却 3 秒；浏览器需要权限时按提示授权。
- `R` 重新开始，`M` 切换音效，也可以使用页面上的按钮。
- 切到后台自动暂停并保存，狗堆、警戒倒计时和本局时长均停止；重新打开同一浏览器可选择“继续上次”或“新开一局”。本局结束或重新开始会清除续局存档。
- 两只同级狗碰撞后升级；两只 10 级狗合成时清除并获得 200 分，显示“大狗叫！！”并播放录音，伴随短暂停顿与柔和的扩散光圈。
- 已落地的狗在警戒线以上停住约 1.5 秒，本局结束。
- 结算页显示本局时长、投放次数和最高等级；时长从首次成功投放开始，切到后台期间暂停计时。
- 最高分和音效设置保存在当前浏览器中。
- 结束后可点击“保存成绩图”：手机长按图片保存，电脑点击下载；图片包含本局成绩、最高等级、时长、投放次数和游戏二维码。

## 图片加载

页面使用 WebP 狗图，PNG 保留为原图。先准备 1～4 级，其他等级后台加载；慢网时使用同一张狗图的内联缩略版，清晰图到位后自动替换。加载失败可以在棋盘下方重试，不中断当前游戏。

## 音频

“大狗叫”录音位于 `assets/dagou-bark.mp3`。关闭音效或重新开始会停止播放，连续触发时从头播放。
